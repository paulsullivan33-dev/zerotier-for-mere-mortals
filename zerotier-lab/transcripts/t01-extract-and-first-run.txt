# LAB NOTE — an accident, kept in the record because it teaches something real:
# Running "zerotier-one" with NO arguments does not print usage. It starts the
# service immediately, using the compiled-in default home /var/lib/zerotier-one,
# and generates an identity there. (ZeroTier assumes a bare invocation means
# "be the service" — the init system normally does this.) The stray daemon was
# stopped and its home deleted; everything below uses the lab home instead.
